You are a senior full-stack software architect and developer.

Your task is to build **Stock Pro** completely from scratch as a production-quality monorepo.

Do not copy old project code.

Work **phase by phase**. Do not jump ahead.

After each phase:

1. Implement the phase completely.
2. Run lint.
3. Run type checking.
4. Run relevant tests.
5. Run build where applicable.
6. Fix every error introduced by the phase.
7. Give me:

   * files created

# 24. Prisma Transactions

Use transactions for workflows involving multiple dependent writes.

Examples:

```text
complete order + deduct inventory + create stock movements + create payment
complete return + restore stock + create stock movement + create refund
repair completion + parts consumption + stock movement
```

The operation must either complete entirely or roll back entirely.

---

# 25. Concurrency

Inventory cannot become incorrect because two sales happen simultaneously.

Design inventory updates to avoid naive:

```text
read quantity
subtract in JavaScript
save quantity
```

Use transactional/atomic database operations and validate available stock inside the transaction.

Prevent negative inventory unless the business rule explicitly allows it.

---
